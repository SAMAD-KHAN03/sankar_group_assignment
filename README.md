A full-featured **Task Manager** mobile application built with Flutter as part of the **Sankar Group Flutter Development Internship Assignment**. The app supports Firebase Authentication, real-time Cloud Firestore task management, REST API integration for motivational quotes, and a clean Material Design 3 UI.

---

## ✨ Features

### 🔐 User Authentication
- Sign Up with email & password
- Login with email & password
- Logout with confirmation dialog
- User-friendly error messages for all auth exceptions
- Persistent session (auto-login on relaunch)

### 📝 Task Management (CRUD)
- **Add** tasks with title, description, due date, and status
- **Edit** any existing task
- **Delete** tasks with a confirmation dialog
- **Mark** tasks as Completed or Pending with a single tap
- Real-time sync powered by Firestore streams
- Tasks are filtered per logged-in user

### 💬 REST API Integration
- Fetches a random motivational quote from `https://api.quotable.io/random`
- Displays the quote text and author
- Refresh button to load a new quote
- Graceful error handling with retry option

### 🎨 UI / UX
- Material Design 3 with Google Fonts (Poppins)
- Tab-based filtering: **All / Pending / Completed**
- Animated loading indicators (SpinKit)
- Form validation on all input fields
- Confirmation dialogs before destructive actions
- Responsive layout — works on Android & iOS

## 🚀 Setup & Installation

### Prerequisites

Make sure you have the following installed:

- [Flutter SDK](https://flutter.dev/docs/get-started/install) ≥ 3.0.0
- Dart SDK ≥ 3.0.0
- Android Studio or VS Code with Flutter & Dart extensions
- A [Firebase](https://firebase.google.com) account
- A physical Android device or emulator (API 21+)

---

### Step 1 — Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/task_manager.git
cd task_manager
```

---

### Step 2 — Create the Folder Structure

```bash
mkdir -p lib/models lib/services lib/screens lib/widgets lib/utils
```

---

### Step 3 — Install Dependencies

```bash
flutter pub get
```

---

### Step 4 — Create a Firebase Project

1. Go to [Firebase Console](https://console.firebase.google.com)
2. Click **Add project** → enter a name (e.g. `task-manager-app`) → **Continue**
3. Disable Google Analytics (optional) → **Create project**

---

### Step 5 — Enable Firebase Authentication

1. In the Firebase Console, go to **Authentication** → **Get started**
2. Click the **Sign-in method** tab
3. Enable **Email/Password** → click **Save**

---

### Step 6 — Enable Cloud Firestore

1. In the Firebase Console, go to **Firestore Database** → **Create database**
2. Select **Start in test mode** (for development)
3. Choose a region close to you → **Enable**

**Recommended Security Rules (for production):**

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /tasks/{taskId} {
      allow read, update, delete: if request.auth != null
                                  && request.auth.uid == resource.data.userId;
      allow create: if request.auth != null
                    && request.auth.uid == request.resource.data.userId;
    }
  }
}
```

---

### Step 7 — Connect Flutter to Firebase (FlutterFire CLI)

Install the FlutterFire CLI:

```bash
dart pub global activate flutterfire_cli
```

Run the configure command from inside your project folder:

```bash
flutterfire configure
```

> This will:
> - Auto-generate `lib/firebase_options.dart` with your project's real credentials
> - Download `google-services.json` into `android/app/`
> - Download `GoogleService-Info.plist` into `ios/Runner/`

---

### Step 8 — Configure Android

In `android/app/build.gradle`, make these two changes:

```gradle
// 1. Apply the Google Services plugin
plugins {
    id "com.android.application"
    id "kotlin-android"
    id "dev.flutter.flutter-gradle-plugin"
    id "com.google.gms.google-services"   // ← Add this line
}

// 2. Set minSdkVersion to 21 (required by Firebase)
defaultConfig {
    minSdkVersion 21                       // ← Change to 21
    ...
}
```

In `android/build.gradle`, add inside `buildscript > dependencies`:

```gradle
classpath 'com.google.gms:google-services:4.4.1'
```

---

### Step 9 — Run the App

```bash
# Run on a connected device or emulator
flutter run

# Run in release mode
flutter run --release
```
